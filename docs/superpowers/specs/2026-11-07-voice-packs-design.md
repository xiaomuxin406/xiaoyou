# 小优 1.0.0 本机克隆语音包

用户已明确选择：上传 MP3 后，用其音色朗读所有新回复，接入本机语音克隆引擎。沿用已授权的自动工具执行、中断思考、Windows 10/11 桌面与本机网页。

采用 F5-TTS 中文零样本合成，不以重复播放参考录音冒充朗读。Python 独立环境安装依赖及模型；Node 管理辅助进程、取消、超时和本机会话认证。语音模型缓存和依赖不提交 Git。模型许可证与安装说明随源码提供。

`voice-packs/` 为项目语音包目录。预置用户提供的 `ttsmaker-file-2026-11-7-20-30-54.mp3`。设置支持上传 MP3、试听原音、自动转录参考文字、编辑识别结果、选择系统语音或克隆语音包、测试合成。上传成功后自动选择新语音包并持久化；目录新增 MP3 可自动发现并导入。无效或损坏文件不替换当前选择。

参考录音解码成单声道 WAV，取最多 12 秒，使用本地 Vosk 自动识别参考文字。参考文字与参考音频共同传给 F5-TTS；识别失败时明确要求校正，不用猜测文字。合成的新音频通过受认证接口返回，播放状态驱动星云并暂停唤醒采集。停止朗读或中断思考取消请求、终止未完成合成、停止播放并释放对象 URL。

配置使用 `voicePackId`、`ttsPythonPath`；语音包索引及归一化音频存于项目 `.runtime/voice-packs`，公开目录仅放 MP3 样本。源文件使用散列标识防止路径穿越、重复导入；音频大小上限 15 MiB。导入与合成串行，操作日志显示状态。引擎不可用时显示安装或路径配置提示，不静默换成系统音色。

API：GET `/api/voice-packs`；POST `/api/voice-packs/import?name=...` 原始 MP3；PATCH `/api/voice-packs/:id` 更新参考文字；GET `/api/voice-packs/:id/audio` 试听；GET `/api/tts/status`；POST `/api/tts/install`；POST `/api/tts/speak` `{text,voicePackId?}` 返回 WAV；POST `/api/tts/cancel`。所有接口沿用本机会话认证及同源检查。

发行版本统一为 `1.0.0`，生成 Windows x64 便携程序。先通过文件导入、自动切换、持久化、取消、真实中文合成、网页及桌面验证，再审查 Git 待提交文件，推送已授权 GitHub 仓库；排除密钥、对话记忆、本机 MCP 路径、依赖及大型模型。
